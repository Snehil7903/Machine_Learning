1. What is a loss function?
A neural network produces a prediction: y^
We know the actual answer:y
The loss function measures how different the prediction is from the actual answer.
L=Loss(y^,y)
The optimizer then tries to minimize this loss.
So our complete pipeline is:
Input
  ↓
Neural Network
  ↓
Prediction ŷ
  ↓
Loss Function
  ↓
Loss
  ↓
backward()
  ↓
Gradients
  ↓
Optimizer
  ↓
Updated parameters
The loss is therefore the signal that tells the network how badly it is performing.



2. Loss vs Accuracy
These are NOT the same thing.
Suppose we're doing binary classification.
Actual:y=1
Prediction:y^=0.51
The model gets the classification correct because:0.51>0.5
So accuracy says:
Correct ✅
But another model might predict:
y^=0.99

Both are correct according to accuracy.
But the second model is much more confident.
A good loss function can distinguish these predictions.
That's why during training we generally optimize loss, not accuracy.


3. Regression Loss: MSE
Let's start with the simplest one.
Mean Squared Error
![alt text](image.png)
Suppose:
Actual = 10
Prediction = 7
Error:10−7=3
Squared error:3^2=9
So:L=9

import torch
loss_fn = torch.nn.MSELoss()
prediction = torch.tensor([7.0])
target = torch.tensor([10.0])
loss = loss_fn(prediction, target)
print(loss)

Output:
tensor(9.)


4. Why square the error?
Suppose we didn't square.
If:error=+5
and:error=−5

they would cancel each other if averaged.
But we want both to represent an error of magnitude 5.
Squaring gives: (+5)^2=25 
                (-5)^2=25 
So errors cannot cancel.
There is another important property:
Large errors are penalized disproportionately.
For example:2^2=4 
but: 10^2=100 
So MSE strongly penalizes large mistakes.



5. MSE gradient
For a single example:L=(y'-y)^2 
Derivative with respect to prediction:​∂L/∂y'​=2(y'​−y)​
This is important because that gradient eventually travels backward into the neural network.
For example: y'=7,y=10
Then:∂L/∂y'=2(7−10)=−6
That negative gradient tells the network that its prediction needs to move upward.
